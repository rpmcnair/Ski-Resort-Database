# 304 Project: Ski Resort Data Base

This database can be used by ski resort management to keep track of the status of all parts of the mountain. Ski instructors can use the lift and class information to see what parts of the mountain are open as well as what runs have many classes running on them to plan out where they will take their class on the mountain. Upper management can use the information regarding patrons, passes, and dining locations to drive future pricing and improvements to the resort. Maintenance crews can use lift and run status to see where maintenance is needed on the mountain and help reduce downtime.
